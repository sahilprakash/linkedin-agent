## Idea 5 — Power BI & DAX
**Topic:** Using CALCULATE Like a Conductor

**Hook:** CALCULATE is the baton that orchestrates context changes.

**Full Draft:**

CALCULATE is the baton that orchestrates context changes.

I often see people confused by the difference between a measure and a calculated column. CALCULATE lets you modify the filter context before performing a calculation, making it the most powerful DAX function.

A quick pattern: 
1) Define a filter with FILTER or a simple logical expression. 
2) Pass that filter to CALCULATE. 
3) Return the aggregation.

For example, to get the total sales for the current year:

SalesCY = CALCULATE(SUM(Sales[Amount]), FILTER(ALL('Calendar'), 'Calendar'[Year] = YEAR(TODAY())))

This keeps the logic tidy and avoids context‑transition headaches.
