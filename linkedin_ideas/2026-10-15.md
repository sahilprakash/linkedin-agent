## Idea 5 — Power BI & DAX
**Topic:** Choosing measures vs calculated columns for performance

**Hook:** Choosing the wrong one costs you performance and clarity.

**Full Draft:**

Choosing the wrong one costs you performance and clarity.

Calculated columns run during data refresh, while measures calculate on the fly. If you need a value that changes with slicers, a measure is the only option – otherwise you’ll see unexpected blanks.

Conversely, use a calculated column when the value is static across all visuals, like a fiscal quarter derived from a date. It saves the engine from recomputing the same expression for every visual interaction.
